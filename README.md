A 2D canvas cooking game built for the [make.fun](https://make.fun/bounty/best-cooking-game-20261125-0137) competition "Make the best cooking game".

## The game

Run a busy kitchen in a 150-second shift: take orders from the board, chop ingredients, cook on the stove, assemble dishes at the counter, and serve them before the timer runs out. Combos reward streaks; burnt dishes go in the bin.

- **3 original recipes:** Sunny Rice Bowl, Ember Burger, Garden Crunch
- **Controls:** keyboard + mouse
- **Art:** all drawn on canvas; **sound:** all synthesized with WebAudio — no network, no external assets

## Play

Open `game/index.html` in a browser, or run `main.ts` to generate the game dossier.
